# Portfólio de Enzo Araújo

Este projeto é um portfólio pessoal desenvolvido em HTML e CSS para apresentar informações sobre Enzo Lemes, seus projetos, trajetória profissional e formas de contato.

## Visão geral

- Página inicial com apresentação pessoal
- Seção de sobre mim
- Galeria de projetos
- Timeline de skills e trajetória
- Área de contato com WhatsApp, e-mail, LinkedIn e GitHub
- Layout responsivo e visual moderno

## Estrutura do projeto

```text
portfolio-main/
├── index.html
├── assets/
│   ├── css/
│   │   └── portfolio.css
│   └── img/
│       ├── projetos/
│       └── sobre-foto/
└── docs/
    └── README.md
```

## Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts
- Imagens locais em pasta de assets

## Como executar

1. Baixe ou clone o projeto.
2. Abra o arquivo `index.html` em um navegador.
3. Se quiser usar um servidor local, pode iniciar facilmente com qualquer servidor estático, por exemplo:

```bash
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```

## Arquivos principais

- [assets/css/portfolio.css](assets/css/portfolio.css): estilos e layout
